# Supporters

geotechCLI is Apache-2.0 open source and free for everyone. Sponsorship covers hosted AI
usage, cross-platform testing, documentation, security maintenance, and the time required to
review contributions and ship dependable releases.

Recognition on this page is **optional and opt-in**. Sponsors are listed only if they ask to
be — sponsoring privately is equally welcome and changes nothing about how the project treats
your issues or pull requests.

> Sponsorship is optional and never changes access to the project. It does not purchase
> engineering approval, an SLA, roadmap control, or a guaranteed feature. Priorities remain
> based on safety, community value, and maintainer capacity.

## How to be listed

Sponsor via [GitHub Sponsors](https://github.com/sponsors/kilickursat) or
[Patreon](https://www.patreon.com/16003704/join), then open a pull request adding your name (and
optionally a link) to the appropriate section, or mention it in your sponsorship message and it
will be added for you.

## Contributing without sponsoring

Reporting an issue, improving the documentation, proposing a test case, or opening a pull
request are all equally valuable. See [CONTRIBUTING.md](CONTRIBUTING.md).
