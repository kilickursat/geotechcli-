# geotechcli

**Open-source agentic AI CLI for geotechnical engineering** — deterministic engines
(bearing, liquefaction, settlement, slope, pile, tunnel, …) plus an AI agent over an
evidence-bound GroundModel. The AI interprets; deterministic code owns every number.

AI works out of the box — hosted GLM 5.2 included free, no API key, no signup.
BYOK (OpenAI, Anthropic, Zhipu, OpenAI-compatible, Hugging Face) supported.

```bash
npm install -g geotechcli

geotech analyze .              # folder of geotech data → evidence-bound GroundModel
geotech chat                   # AI agent with your project auto-loaded
geotech liquefaction --demo    # deterministic screening on sample data
geotech --help                 # everything else
```
