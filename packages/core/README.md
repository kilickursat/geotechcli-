# @geotechcli/core

Core library for [geotechCLI](https://github.com/kilickursat/geotechcli-) — the open-source
agentic AI CLI for geotechnical engineering. This package contains the deterministic
calculation engines (bearing, liquefaction, settlement, slope, pile, retaining, seepage,
tunnel/TBM), the evidence-bound GroundModel and verifier, document ingest/OCR contracts,
signal analysis, the agent runtime with its fail-closed guardrails, LLM provider adapters
(hosted GLM, OpenAI, Anthropic, Zhipu, OpenAI-compatible, Hugging Face), and the bundled
skill catalog.

Most users want the CLI instead:

```bash
npm install -g geotechcli
```
